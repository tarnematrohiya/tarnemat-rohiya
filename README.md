# ترنيمات روحية

برنامج مجاني لعرض **الترانيم الروحية** و**الكتاب المقدس** (ترجمة فان دايك المشكولة) على البروجكتور في الكنيسة.

## ⬇️ [تحميل البرنامج](https://tarnematrohiya.github.io)

- Windows 10 / 11 و Windows 7 / 8
- بيشتغل من غير إنترنت، وبيتحدّث لوحده لما يكون فيه إنترنت.
- وصّل البروجكتور واعمل <bdi>Extend</bdi> (ويندوز + <bdi>P</bdi>) وشاشة العرض بتفتح عليه لوحدها.
